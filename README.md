Peripheral API documentation and TypeScript/Lua examples are available on the
[Digital Items documentation site](https://siredvin.github.io/DigitalItems/).

The `multiversion` branch maintains Minecraft **1.20.1 Fabric/Forge**,
**1.21.1 Fabric/NeoForge**, and **26.1.2 Fabric/NeoForge** together.
**26.1.2 requires Java 25 and new worlds; cross-version world upgrades and downgrades are not supported.**

build/test commands, canonical source ownership, artifact names and docs previews.
